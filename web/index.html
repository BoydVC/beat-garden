About Beat Garden

Beat Garden is a fun offline drum pad + reactive visualizer for Char and Vic — tap on iPad/iPhone Safari or any browser.

  • 16 colorful pads (kick / snare / hat / tom / perc / fx)
  • Bloom visualizer reacts to every hit
  • 8- or 16-step sequencer with BPM
  • 4 EXAMPLE kits: Garden, Space, Arcade, Rain
  • Saves last pattern in localStorage

TokenMax burn build · pure client-side Web Audio · no cloud · no CDN samples required.

Keyboard: number row + QWERTY map to the 16 pads.
